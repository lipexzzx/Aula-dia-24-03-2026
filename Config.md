# PASSO A PASSO DE COMO INSTALAR E CONFIGURAR O DJANGO
First Step:

Abra o Prompt de Comando e digite esses seguintes Comandos:
```
mkdir django_aulas
cd django_aulas
```

# Explicação

O comando ``mkdir django_aulas``, cria um diretório/pasta para você manusear o seu projeto.
Já o comando ``cd django_aulas``, entra diretamente no diretório que você criou.

**Second Step:**

Estando dentro do diretório, você digitará o comando ``python -m venv venv``, que criará um ambiente virtual que possibilita instalar pacotes e bibliotecas de um determinado projeto.

**Third Step:**

Após entrar no Ambiente Virtual você digitará o comando ``django-admin --version``, esse comando basicamente verificará a versão que está o django no seu diretório, caso não esteja você deve usar este seguinte comando ``pip install django``, que basicamente instalará o django no seu diretório.

**Fourth Step:**

Tendo feito as etapas acima você executará este comando ``django-admin startproject meu_projeto``, que começará o seu projeto.

**Fifth Step:**

Você executará o comando ``cd meu_projeto``, que irá abir o dirétorio do seu projeto.

**Sixth Step:**

Estando dentro do diretório meu_projeto, você executará o seguinte ``código code .`` que abrirá o Visual Studio Code como ferramenta de visualização e edição.

**Seventh Step:**

Dentro do VSCode use o Seguinte atalho CRTL + ', que irá abrir o terminal integrado dentro do VSCode.

**Eighth step:**

Após ter feito a etapa acima execute o seguinte comando ``python manage.py runserver``, que roda o projeto na máquina local via DJANGO.

# STEP-BY-STEP GUIDE ON HOW TO INSTALL AND CONFIGURE DJANGO

**First Step:**

Open the Command Prompt and type the following commands:

```
mkdir django_aulas
cd django_aulas
```

# Explanation

The command `mkdir django_aulas` creates a directory/folder for you to manage your project.
The command `cd django_aulas` allows you to enter the directory you just created.

---

**Second Step:**

Inside the directory, type the command `python -m venv venv`, which will create a virtual environment that allows you to install packages and libraries for a specific project.

---

**Third Step:**

After activating the virtual environment, type the command `django-admin --version`. This command checks which version of Django is installed in your directory.
If Django is not installed, use the following command: `pip install django`, which will install Django in your directory.

---

**Fourth Step:**

After completing the previous steps, run the command `django-admin startproject meu_projeto`, which will create your project.

---

**Fifth Step:**

Run the command `cd meu_projeto`, which will open your project directory.

---

**Sixth Step:**

Inside the `meu_projeto` directory, run the following command: `code .`, which will open Visual Studio Code as your code editor.

---

**Seventh Step:**

Inside VS Code, use the following shortcut `CTRL + '` to open the integrated terminal.

---

**Eighth Step:**

After completing the previous step, run the command `python manage.py runserver`, which will start the project locally using Django.
